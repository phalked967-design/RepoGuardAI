\# RepoGuard AI



AI-powered repository analysis and engineering risk detection tool.



\## Features



\- Repository structure scanning

\- Engineering risk detection

\- Hard-coded secret detection

\- AI-powered analysis using a local LLM

\- MCP-based repository scanning

\- JSON and Markdown reports



\## Tech Stack



\- Python

\- Ollama

\- Qwen2.5-Coder

\- MCP

\- Git



\## How It Works



Repository → Scanner → Engineering Findings → AI Analysis → Report
